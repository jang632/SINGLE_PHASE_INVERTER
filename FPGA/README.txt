Fixed-Point Formats
Information regarding the fixed-point formats for individual signals is included in the comments directly next to the port declarations in the source files.

Compilation Requirements (VHDL-2008)
Modules utilizing 2D arrays of the type type t_array is array (natural range <>) of signed; must be declared and compiled using the VHDL-2008 standard.
